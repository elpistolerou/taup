# TAUP Medical Center Website

This project is a multi-page, responsive website designed for a medical center (clinic/hospital). The project is built using HTML, CSS, and JavaScript, with UI libraries integrated.

## Project Description

The website serves as an online presentation platform for the clinic. Users can access:

Information about the clinic

-**Doctors’ profiles**

-**News section**

-**Photo gallery**

-**Navigation menu**

and other related sections.

## Features

-**Responsive design**:mobile, tablet, desktop

-**Multi-page structure**

-**Individual pages for doctors**

-**Image gallery with Lightbox effect**

-**Interactive navigation (JavaScript)*

-**Modern UI elements**

-**Icon libraries**
